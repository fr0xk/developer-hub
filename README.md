# Developer Hub

A smart, consolidated monorepo for developer tools, handbook resources, and automation scripts.

## Directory Structure
- `src/rust/`: Core Rust projects and standalone utilities.
- `src/python/`: Automation, AI modules, and examples.
- `scripts/`: Maintenance and documentation tools.
- `docs/`: Automatically generated system documentation.

## Maintenance
- **Commit Guidelines**: See [CONTRIBUTING.md](./CONTRIBUTING.md).
- **Documentation**: Run `./scripts/generate_docs.sh` to update local docs.
- **Versioning**: Use `git tag` for releases.
