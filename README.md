# Developer Hub

A collection of tools, configs, and utilities for Android development with Termux.

## 📦 Package Backup System

This repo includes a **reproducible package manifest** for your Termux environment:

- [`backup.py`](backup.py): Python script to backup/restore explicitly installed packages.
- [`backups/`](backups/): Contains current lists of:
  - Termux packages (`termux-packages.txt`)
  - pip packages (`pip-packages.txt`)
  - (empty) npm & cargo — none installed globally

👉 See [`backups/README.md`](backups/README.md) for full details, format, and usage.

### Quick Commands
```bash
# Backup current explicit packages
python3 backup.py --backup

# Restore (interactive confirmation required)
python3 backup.py --restore

# Sync & report changes
python3 backup.py --sync
```
